How to read this

Each step is a function in one repository. The pill between steps is the hop: HTTP, gRPC, an event, or a return. Click a step to open its code.

Inside a code block, use Show more lines above or below the function to grow the context, Fit function to come back, and Whole file to see everything embedded. The orange marker is the line where the next hop starts — click it to jump.

Snippets are embedded when the page is generated, so this file works offline and can be attached to a ticket or a review. Hops are asserted by the chain author unless an indexer verified them; the blob hash in each step is the source file's checksum at build time. Keyboard: j/k move between steps, e expands, / searches.
